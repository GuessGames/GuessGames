## Main Focus — Forge RP

I develop **Forge RP**, a private **RedM** roleplay server.

Most of my real work lives in closed repositories: gameplay systems, economy, jobs, world immersion, and the day-to-day stability of a live RP server.

Public GitHub here is only a small slice — the core Forge RP codebase stays private.

```text
Forge RP  ·  RedM  ·  RSG-Core stack  ·  closed source
```

### What I ship on Forge RP
- Custom RedM resources & server systems
- Roleplay loops: jobs, economy, world interactions
- Stability, UX, and production-ready gameplay polish
- Private tooling around a live frontier server
